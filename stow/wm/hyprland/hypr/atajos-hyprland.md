# Atajos de Hyprland

SUPER = tecla Windows. Config: `~/.config/hypr/bindings.conf`

## Aplicaciones
| Atajo | Acción |
|---|---|
| `SUPER+ENTER` | Terminal (kitty) |
| `SUPER+SHIFT+ENTER` | Navegador (Chrome) |
| `SUPER+SHIFT+F` | Archivos (thunar) |
| `SUPER+SHIFT+N` | Editor (nvim) |
| `SUPER+ESPACIO` / `ALT+ESPACIO` | Launcher (rofi) |
| `SUPER+K` | Cambiar ventana (rofi) |
| `SUPER+CTRL+ESPACIO` | Cambiar fondo de pantalla |
| `SUPER+SHIFT+I` | Color de las islas de la barra |

## Ventanas
| Atajo | Acción |
|---|---|
| `SUPER+W` | Cerrar ventana |
| `SUPER+F` | Pantalla completa |
| `SUPER+ALT+F` | Fullscreen maximizado |
| `SUPER+T` / `SUPER+O` | Flotante / tiling |
| `SUPER+J` | Cambiar split |
| `SUPER+P` | Pseudo-tile |
| `SUPER+↑↓` | Mover foco |
| `SUPER+SHIFT+↑↓` | Mover ventana |

## Workspaces
| Atajo | Acción |
|---|---|
| `SUPER+1..9` | Ir al workspace |
| `SUPER+SHIFT+1..9` | Mover ventana + ir |
| `ALT+1..9` | Mover ventana al workspace + ir |
| `SUPER+←/→` | Workspace anterior/siguiente |
| `SUPER+SHIFT+←/→` | Mover ventana al workspace anterior/siguiente |
| `SUPER+rueda` | Cambiar workspace |
| `SUPER+clic` arrastrar | Mover ventana flotante |

## Portapapeles universal
| Atajo | Acción |
|---|---|
| `SUPER+C` | Copiar (CTRL+C) |
| `SUPER+V` | Pegar (CTRL+V) |
| `SUPER+X` | Cortar (CTRL+X) |
| `SUPER+SHIFT+V` | Historial del portapapeles |

## Sistema
| Atajo | Acción |
|---|---|
| `SUPER+ESC` | Menú energía (apagar/reiniciar/suspender) |
| `SUPER+SHIFT+Q` | Cerrar sesión |
| `SUPER+SHIFT+S` | Screenshot (seleccionar área, se guarda en Imágenes/Screenshots) |
| Teclas de volumen | Subir/bajar/mutar volumen |
| Teclas de brillo | Subir/bajar brillo |
| Tecla touchpad | Activar/desactivar touchpad |

## Barra (clics)
| Elemento | Acción |
|---|---|
| Clic en red / bluetooth | Panel Wi-Fi + Bluetooth |
| Clic en volumen | pavucontrol |
| Clic en disco | Abrir thunar |
| Clic en ⏻ | Menú energía |
| Clic derecho en ⏻ | Bloquear pantalla |
